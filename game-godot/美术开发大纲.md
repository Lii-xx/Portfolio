### 1.6 模块化设计原则（用户强调）
- **数据驱动**：卡牌/怪物数据全在JSON，新增只需加文件
- **策略模式**：效果脚本独立，通过 EffectRegistry 注册
- **信号解耦**：逻辑层通过 EventBus 发信号，表现层监听
- **新增美术不应破坏现有架构**，尽量在现有工具类中扩展

### 1.7 开发规范与设计模式术语（项目已隐含使用）

> 本项目虽然代码量不大，但已经遵循了多项软件工程规范。理解这些术语有助于后续维护和面试表达。

#### 已在使用的术语

| 术语 | 中文 | 含义 | 项目里的体现 |
|------|------|------|--------------|
| **Modular Design** | 模块化设计 | 系统拆成独立模块，互不依赖 | 卡牌/怪物/效果分文件夹独立 |
| **Data-Driven** | 数据驱动 | 内容由数据文件定义，代码只负责加载和解析 | JSON 定义卡牌/怪物，代码通用 |
| **Strategy Pattern** | 策略模式 | 同一接口多种实现，可互换 | 14个卡牌效果脚本 + EffectRegistry 注册 |
| **Observer Pattern** | 观察者模式 | 一方发通知，多方监听，互不认识 | EventBus 信号总线（emit/connect） |
| **Singleton Pattern** | 单例模式 | 全局唯一实例 | Autoload 的 7 个全局单例 |
| **Separation of Concerns** | 关注点分离 | 不同职责分到不同模块 | 逻辑层(GameManager) vs 表现层(UI) 分开 |
| **Object Pool** | 对象池 | 复用对象避免频繁创建销毁 | SFX 的 AudioStreamPlayer 复用 |
| **Caching** | 缓存 | 重复使用的资源预先加载，避免运行时卡顿 | `_bgm_cache` / `_sfx_cache` 预加载 |

#### 可补充了解的术语（大纲隐含但没点名）

| 术语 | 中文 | 含义 | 项目里的体现 |
|------|------|------|--------------|
| **MVC Architecture** | MVC架构 | Model-View-Controller 三层分离 | data(JSON)=Model, ui=View, autoload=Controller |
| **Event-Driven** | 事件驱动 | 通过信号触发行为，而非直接调用 | EventBus.emit / connect |
| **Dependency Injection** | 依赖注入 (DI) | 不在内部 new，由外部传入依赖 | 效果脚本通过 Registry 注册，调用方不关心具体实现 |
| **DRY Principle** | 不要重复自己 | 公共逻辑抽到工具类，避免复制粘贴 | tween_helpers.gd / sprite_helper.gd |
| **KISS Principle** | 保持简单 | 不过度设计，能用简单方案就不复杂化 | 大纲建议"着色器尽量简单"、"粒子数量控制" |
| **Single Responsibility** | 单一职责 | 一个类/文件只做一件事 | 每个脚本职责清晰（如 SoundManager 只管声音） |
| **Open-Closed Principle** | 开闭原则 | 对扩展开放，对修改关闭 | 加新卡牌不改老代码，只新增文件 |
| **Registry Pattern** | 注册表模式 | 集中管理可扩展组件 | CardRegistry / EffectRegistry |
| **Facade Pattern** | 外观模式 | 提供统一接口屏蔽内部复杂度 | SoundManager.play_sfx() 屏蔽了 player 创建/销毁细节 |
| **Lazy Loading** | 懒加载 | 用到时才加载，不用不加载 | BGM 首次播放时才 load()，SFX 启动时预加载 |

#### 一句话总结本项目架构

> "**数据驱动 + 事件总线 + 策略模式** 的模块化架构，遵循 **关注点分离** 和 **开闭原则**。"

这套说法在简历/面试里也通用。

### 2.2 修改 SoundManager（核心改造）

**文件**：`scripts/autoload/sound_manager.gd`

**改造方案**：
```gdscript
extends Node

var _bgm_player: AudioStreamPlayer
var _sfx_players: Dictionary = {}  # name -> AudioStreamPlayer (对象池)
var _bgm_volume: float = 0.3
var _sfx_volume: float = 0.6

# 音频资源路径表（模块化：新增音效只需在此添加一行）
const BGM_PATHS = {
    "title": "res://assets/audio/bgm/title.ogg",
    "battle": "res://assets/audio/bgm/battle.ogg",
    "boss": "res://assets/audio/bgm/boss.ogg",
    "campfire": "res://assets/audio/bgm/campfire.ogg",
    "victory": "res://assets/audio/bgm/victory.ogg",
}

const SFX_PATHS = {
    "ui_click": "res://assets/audio/sfx/ui_click.wav",
    "card_play": "res://assets/audio/sfx/card_play.wav",
    "card_draw": "res://assets/audio/sfx/card_draw.wav",
    "attack_hit": "res://assets/audio/sfx/attack_hit.wav",
    "attack_heavy": "res://assets/audio/sfx/attack_heavy.wav",
    "block": "res://assets/audio/sfx/block.wav",
    "heal": "res://assets/audio/sfx/heal.wav",
    "monster_die": "res://assets/audio/sfx/monster_die.wav",
    "player_hurt": "res://assets/audio/sfx/player_hurt.wav",
    "dice_roll": "res://assets/audio/sfx/dice_roll.wav",
    "buff": "res://assets/audio/sfx/buff.wav",
    "debuff": "res://assets/audio/sfx/debuff.wav",
    "poison": "res://assets/audio/sfx/poison.wav",
    "fire": "res://assets/audio/sfx/fire.wav",
    "level_up": "res://assets/audio/sfx/level_up.wav",
}

# 缓存已加载的音频流
var _bgm_cache: Dictionary = {}
var _sfx_cache: Dictionary = {}

func _ready() -> void:
    _bgm_player = AudioStreamPlayer.new()
    _bgm_player.volume_db = linear_to_db(_bgm_volume)
    add_child(_bgm_player)
    EventBus.sfx_requested.connect(_on_sfx_requested)
    EventBus.bgm_requested.connect(_on_bgm_requested)
    EventBus.bgm_stopped.connect(_on_bgm_stopped)
    _preload_sfx()  # 预加载常用音效

## 预加载SFX到缓存
func _preload_sfx() -> void:
    for sfx_name in SFX_PATHS.keys():
        var stream = load(SFX_PATHS[sfx_name])
        if stream:
            _sfx_cache[sfx_name] = stream

## 播放BGM
func play_bgm(name: String) -> void:
    if _bgm_player.playing and _bgm_player.stream == _bgm_cache.get(name):
        return  # 同一首BGM不重复播放
    var stream = _bgm_cache.get(name)
    if stream == null:
        stream = load(BGM_PATHS.get(name, ""))
        if stream:
            _bgm_cache[name] = stream
    if stream == null:
        return
    _bgm_player.stream = stream
    _bgm_player.play()

## 播放SFX
func play_sfx(name: String) -> void:
    var stream = _sfx_cache.get(name)
    if stream == null:
        return
    var player = AudioStreamPlayer.new()
    player.stream = stream
    player.volume_db = linear_to_db(_sfx_volume)
    player.finished.connect(player.queue_free)
    add_child(player)
    player.play()

## 设置音量（可用于设置菜单）
func set_bgm_volume(vol: float) -> void:
    _bgm_volume = clamp(vol, 0.0, 1.0)
    _bgm_player.volume_db = linear_to_db(_bgm_volume)

func set_sfx_volume(vol: float) -> void:
    _sfx_volume = clamp(vol, 0.0, 1.0)
```

### 2.4 音频格式建议
- **BGM**：`.ogg`（Vorbis），Godot原生支持，体积小，适合循环
- **SFX**：`.wav`（短音效，无延迟）或 `.ogg`（较长音效）
- 采样率：22050Hz 或 44100Hz
- BGM建议带循环点（Godot导入设置中可配置 loop）

### 2.6 新手操作建议

1. **先做 SFX，后做 BGM**：SFX 短小好找，BGM 需要风格统一较难
2. **音量统一**：下载的音效音量可能不一致，用 Audacity 批量归一化（Normalize 到 -3dB）
3. **测试方法**：每加一个音效，运行游戏触发对应场景，确认能听到
4. **避免音效过多**：15 个 SFX 已经够用，不必每个动作都配独特音效
5. **BGM 循环点**：在 Godot 导入设置中勾选 `loop`，否则 BGM 播完就停了

## 三、动画/动效添加方案

### 3.1 方式A：代码 Tween（⭐ 强烈推荐新手使用）

**为什么推荐**：
- 纯代码，不需要在 Godot 编辑器里手动操作
- 改动可见（Git diff 能看到），便于版本管理
- 出问题容易调试（加 `print` 即可）
- 项目已经在用，风格统一

**文件**：`scripts/utils/tween_helpers.gd`

**新增动效函数建议**：

```gdscript
## 卡牌出场（从手牌飞向目标）
static func card_play_to_target(card: Control, target_pos: Vector2) -> void:
    var tween = card.create_tween()
    tween.set_parallel(true)
    tween.tween_property(card, "global_position", target_pos, 0.25).set_ease(Tween.EASE_IN)
    tween.tween_property(card, "scale", Vector2(1.2, 1.2), 0.25)
    tween.chain().tween_property(card, "scale", Vector2(0, 0), 0.15)

## 卡牌抽到手牌（从右侧滑入）
static func card_draw(card: Control) -> void:
    var target_x = card.position.x
    card.position.x = card.position.x + 200
    card.modulate.a = 0.0
    var tween = card.create_tween()
    tween.set_parallel(true)
    tween.tween_property(card, "position:x", target_x, 0.3).set_ease(Tween.EASE_OUT)
    tween.tween_property(card, "modulate:a", 1.0, 0.3)

## 屏幕震动（受击/重击）
static func screen_shake(node: Control, intensity: float = 8.0, duration: float = 0.3) -> void:
    var orig_pos = node.position
    var tween = node.create_tween()
    for i in range(4):
        var offset = Vector2(randf_range(-intensity, intensity), randf_range(-intensity, intensity))
        tween.tween_property(node, "position", orig_pos + offset, duration / 4)
    tween.tween_property(node, "position", orig_pos, 0.05)

## 能量消耗动画（能量数字跳动）
static func energy_spend(label: Label) -> void:
    var tween = label.create_tween()
    tween.tween_property(label, "scale", Vector2(1.5, 1.5), 0.1)
    tween.tween_property(label, "scale", Vector2(1.0, 1.0), 0.2)

## 奖励卡牌弹出
static func reward_card_popup(card: Control) -> void:
    card.scale = Vector2(0, 0)
    var tween = card.create_tween()
    tween.tween_property(card, "scale", Vector2(1.1, 1.1), 0.3).set_ease(Tween.EASE_OUT)
    tween.tween_property(card, "scale", Vector2(1.0, 1.0), 0.1)

## 怪物意图切换提示
static func intent_switch(label: Label) -> void:
    var tween = label.create_tween()
    tween.tween_property(label, "modulate:a", 0.0, 0.15)
    tween.tween_property(label, "modulate:a", 1.0, 0.15)

## 火堆火焰跳动（持续循环）
static func campfire_flicker(node: Control) -> void:
    var tween = node.create_tween().set_loops()
    tween.tween_property(node, "modulate", Color(1.2, 1.0, 0.8, 1), 0.3)
    tween.tween_property(node, "modulate", Color(1.0, 1.0, 1.0, 1), 0.3)
    tween.tween_property(node, "modulate", Color(0.9, 1.1, 1.2, 1), 0.3)
    tween.tween_property(node, "modulate", Color(1.0, 1.0, 1.0, 1), 0.3)
```

### 3.2 方式B：AnimationPlayer 节点（⚠️ 新手有门槛，谨慎使用）

**⚠️ 新手注意**：
- 需要在 Godot 编辑器里手动录制关键帧，操作步骤多
- 录制过程不可代码化，改起来要回编辑器
- 调试困难（看不到具体参数变化）
- **建议**：除非方式A 实在实现不了的效果，否则优先用方式A

**适用场景**：复杂的关键帧动画（如怪物待机呼吸、卡牌翻转）

**步骤**：
1. 在场景中为节点添加 `AnimationPlayer` 子节点
2. Godot编辑器中打开动画面板，录制关键帧
3. 代码中调用：
```gdscript
var anim_player = $AnimationPlayer
anim_player.play("idle_breath")
```

**建议添加的AnimationPlayer动画**：
- 怪物待机呼吸（scale 微微缩放循环）— 也可用 Tween 实现
- 卡牌翻转（出牌时翻面）— 也可用 Tween 实现
- BOSS登场（从屏幕外移入+缩放）— 也可用 Tween 实现
- 火堆火焰跳动 — 也可用 Tween 实现（见 3.1 的 `campfire_flicker`）

> **结论**：本项目所有 AnimationPlayer 动画都可以用 Tween 替代，新手全程用方式A 即可。

### 3.3 方式C：粒子效果（GPUParticles2D）

**适用场景**：受击火花、治疗光效、中毒气泡、火焰

**⚠️ 新手注意**：
- 粒子参数较多（发射方向/角度/速度/颜色/数量/生命周期），调出好看的效果需要反复试
- 建议先抄现成参数，再微调

**步骤**：
1. 节点添加 `GPUParticles2D`
2. 配置 `ParticleProcessMaterial`：
   - 发射方向/角度/速度
   - 颜色渐变（ColorRamp）
   - 数量/生命周期
3. 代码中 `particles.emitting = true` 触发

**建议添加的粒子效果**：

| 效果 | 触发点 | 参数建议 |
|------|--------|----------|
| 攻击命中火花 | `monster_slot.gd` play_hit_animation | 红色，向外扩散，短生命周期 |
| 治疗光效 | `battle_screen.gd` player_healed | 绿色，向上飘，中生命周期 |
| 中毒气泡 | 怪物中毒时 | 紫色，缓慢上升，循环 |
| 格挡护盾 | 玩家获得格挡时 | 蓝色环形，扩散后消失 |
| 火焰 | 烈焰术士攻击时 | 橙红色，向上跳动 |
| 死亡消散 | `monster_slot.gd` play_death_animation | 灰色，向上消散 |

**现成粒子参数参考**（攻击命中火花）：
```gdscript
# 在 monster_slot.gd 中添加
var hit_particles = GPUParticles2D.new()
var mat = ParticleProcessMaterial.new()
mat.direction = Vector3(0, 0, 0)  # 全方向
mat.spread = 180.0
mat.initial_velocity_min = 50.0
mat.initial_velocity_max = 150.0
mat.color = Color.RED
mat.scale_min = 0.5
mat.scale_max = 1.5
hit_particles.process_material = mat
hit_particles.amount = 15
hit_particles.lifetime = 0.3
hit_particles.one_shot = true
hit_particles.emitting = false  # 默认不发射
add_child(hit_particles)

# 受击时触发
hit_particles.emitting = true
```

### 5.2 建议添加的着色器

| 着色器 | 用途 | 参数 |
|--------|------|------|
| `hit_flash.gdshader` | 受击闪白 | flash_intensity (0-1) |
| `freeze.gdshader` | 冰冻效果 | ice_amount (0-1), 蓝色调 |
| `poison.gdshader` | 中毒变绿 | poison_amount (0-1), 绿色调 |

| `dissolve.gdshader` | 死亡溶解 | dissolve_amount (0-1), 噪声纹理 |
| `glow.gdshader` | 发光效果 | glow_color, glow_intensity |

### 5.3 着色器使用方式
```gdscript
# 创建材质
var mat = ShaderMaterial.new()
mat.shader = load("res://shaders/hit_flash.gdshader")
mat.set_shader_parameter("flash_intensity", 0.0)

# 应用到节点
sprite.material = mat

# 动画过渡
var tween = create_tween()
tween.tween_property(mat, "shader_parameter/flash_intensity", 1.0, 0.05)
tween.tween_property(mat, "shader_parameter/flash_intensity", 0.0, 0.15)
```

### 5.4 受击闪白着色器示例
```glsl
// hit_flash.gdshader
shader_type canvas_item;

uniform float flash_intensity : hint_range(0.0, 1.0) = 0.0;
uniform vec4 flash_color : source_color = vec4(1.0, 1.0, 1.0, 1.0);

void fragment() {
    vec4 color = texture(TEXTURE, UV);
    COLOR = mix(color, flash_color, flash_intensity);
}
```

### 5.5 新手注意事项

- **着色器语言是 GLSL**，与 GDScript 语法不同，需要单独学
- **gl_compatibility 渲染器不支持高级特性**（如 3D 着色器、复杂光照）
- **建议**：直接抄 5.4 的示例改参数，不要从零写
- **调试方法**：着色器出错会在 Godot 控制台报错，看行号定位

## 七、注意事项

### 7.1 性能考虑
- 粒子数量控制在 50-100 个以内，避免卡顿
- Tween 动画用 `set_parallel(true)` 并行执行，减少总时长
- 音频文件预加载到缓存，避免运行时加载卡顿
- 着色器尽量简单，gl_compatibility 渲染器不支持高级特性

### 7.2 模块化原则
- **音效**：所有路径集中在 `SoundManager` 的 `BGM_PATHS` / `SFX_PATHS` 字典，新增只需加一行
- **动效**：所有 Tween 函数集中在 `tween_helpers.gd`，调用方不关心实现
- **着色器**：每个着色器独立文件，通过 `ShaderMaterial` 参数控制
- **美术资源**：路径在 JSON 数据文件中配置，代码只负责加载

### 7.3 与HTML对齐
- 动效风格参考 `game.html` 的 CSS transition/animation
- HTML 中已有的动效：卡牌hover放大、受击抖动、伤害飘字、HP条过渡
- Godot 中已对齐上述动效，新增动效保持风格一致

### 7.4 测试方法
- 每个阶段完成后用 godot-mcp 的 `run_project` + `get_debug_output` 验证
- 使用 KEY_K 秒杀快捷键快速测试战斗动效
- 检查控制台无报错

### 7.5 新手常见坑（补充）

| 坑 | 表现 | 解决 |
|----|------|------|
| 音频文件路径错误 | 控制台报 `load()` 返回 null | 检查路径大小写、扩展名、文件是否在 `res://` 下 |
| 音量不一致 | 有的音效震耳欲聋，有的听不见 | 用 Audacity 批量 Normalize 到 -3dB |
| Tween 没执行 | 动画不播放 | 检查节点是否在场景树中、`create_tween()` 的节点是否有效 |
| 粒子看不见 | GPUParticles2D 没效果 | 检查 `emitting = true`、`amount > 0`、材质是否赋值 |
| 着色器报错 | 控制台 GLSL 编译错误 | 看报错行号，检查语法（GLSL 不是 GDScript） |
| 图片透明背景变黑 | PNG 导入后背景黑色 | Godot 导入设置中检查 `Compress > Lossy` 改为 `Lossless` |
| 资源没更新 | 改了图片但游戏里没变 | Godot 编辑器中右键资源 → Reimport |

### 7.6 版本管理建议

- 每完成一个阶段就 git commit 一次，便于回滚
- 美术资源文件较大，建议加 `.gitignore` 排除原始素材（只保留处理后的）
- commit message 示例：`feat(audio): 添加5个SFX音效` / `fix(tween): 修复卡牌出场动画不消失`

## 十、术语速查表（完整版）

> 集中列出本项目涉及的所有软件工程术语，便于查阅和面试表达。

### 10.1 设计模式（Design Patterns）

| 术语 | 中文 | 一句话解释 | 项目体现 |
|------|------|------------|----------|
| Strategy Pattern | 策略模式 | 同一接口多种实现可互换 | 14个卡牌效果脚本 + EffectRegistry |
| Observer Pattern | 观察者模式 | 一发多收，松耦合通知 | EventBus 信号总线 |
| Singleton Pattern | 单例模式 | 全局唯一实例 | 7个 Autoload 单例 |
| Registry Pattern | 注册表模式 | 集中管理可扩展组件 | CardRegistry / EffectRegistry |
| Facade Pattern | 外观模式 | 统一接口屏蔽内部复杂度 | SoundManager.play_sfx() |
| Object Pool | 对象池 | 复用对象避免频繁创建销毁 | SFX 的 AudioStreamPlayer |
| Factory Pattern | 工厂模式 | 封装对象创建过程 | （可扩展方向）卡牌创建 |

### 10.2 架构模式（Architecture Patterns）

| 术语 | 中文 | 一句话解释 | 项目体现 |
|------|------|------------|----------|
| MVC | MVC架构 | Model-View-Controller 三层分离 | data=Model, ui=View, autoload=Controller |
| Event-Driven | 事件驱动 | 通过信号触发行为 | EventBus.emit / connect |
| Data-Driven | 数据驱动 | 内容由数据文件定义 | JSON 定义卡牌/怪物 |
| Layered Architecture | 分层架构 | 按职责分层 | 数据层/逻辑层/表现层 |
| Modular Design | 模块化设计 | 系统拆成独立模块 | 卡牌/怪物/效果分文件夹 |

### 10.3 设计原则（Design Principles）

| 术语 | 中文 | 一句话解释 | 项目体现 |
|------|------|------------|----------|
| SOLID | SOLID原则 | 五大面向对象原则 | 见下方细分 |
| - Single Responsibility | 单一职责 | 一个类只做一件事 | 每个脚本职责清晰 |
| - Open-Closed | 开闭原则 | 对扩展开放，对修改关闭 | 加新卡牌不改老代码 |
| - Liskov Substitution | 里氏替换 | 子类能替换父类 | （可扩展方向）效果脚本继承基类 |
| - Interface Segregation | 接口隔离 | 接口细化，不强迫实现无用方法 | （可扩展方向）效果接口 |
| - Dependency Inversion | 依赖倒置 | 依赖抽象不依赖具体 | EffectRegistry 依赖抽象效果接口 |
| DRY | 不要重复自己 | 公共逻辑抽到工具类 | tween_helpers.gd / sprite_helper.gd |
| KISS | 保持简单 | 不过度设计 | 着色器简单、粒子数量控制 |
| YAGNI | 你不会需要它 | 不提前实现用不到的功能 | 大纲建议分阶段做 |
| Separation of Concerns | 关注点分离 | 不同职责分到不同模块 | 逻辑层 vs 表现层分离 |
| Dependency Injection | 依赖注入 | 由外部传入依赖 | 效果脚本通过 Registry 注册 |

### 10.4 资源管理术语

| 术语 | 中文 | 一句话解释 | 项目体现 |
|------|------|------------|----------|
| Caching | 缓存 | 预加载重复使用资源 | _bgm_cache / _sfx_cache |
| Lazy Loading | 懒加载 | 用到时才加载 | BGM 首次播放才 load() |
| Preloading | 预加载 | 启动时加载常用资源 | _preload_sfx() |
| Asset Bundle | 资源包 | 打包资源便于管理 | （Godot 用 PCK 文件） |
| Garbage Collection | 垃圾回收 | 自动释放无用对象 | GDScript 自动 GC，queue_free() |

### 10.5 Godot 特有术语

| 术语 | 中文 | 一句话解释 | 项目体现 |
|------|------|------------|----------|
| Autoload | 自动加载单例 | 全局可访问的节点 | 7个全局单例 |
| Signal | 信号 | 观察者模式的 Godot 实现 | EventBus 的 signal |
| Node | 节点 | Godot 场景的基本单元 | 所有游戏对象都是 Node |
| Scene | 场景 | 节点树保存为文件 | main.tscn / title_screen.tscn |
| Tween | 补间动画 | 平滑过渡属性值 | tween_helpers.gd 的所有函数 |
| Shader | 着色器 | GPU 程序控制渲染 | crt_scanlines.gdshader |
| ShaderMaterial | 着色器材质 | 应用着色器的材质 | 背景的 ShaderMaterial |
| Resource | 资源 | 可复用的数据对象 | JSON 加载后的卡牌/怪物数据 |
| PackedScene | 打包场景 | 可实例化的场景模板 | preload("xxx.tscn") |

### 10.6 一句话总结本项目架构

> "**数据驱动 + 事件总线 + 策略模式** 的模块化架构，遵循 **关注点分离** 和 **开闭原则**，通过 **注册表模式** 管理可扩展组件，用 **对象池** 和 **缓存** 优化性能。"

## 附录：快速上手清单（新手版）

如果你完全不知道从哪开始，按这个顺序做：

### 第一步：装软件（10分钟）
1. 下载 [Audacity](https://www.audacityteam.org)（免费音频编辑）
2. 下载 [GIMP](https://www.gimp.org) 或 [Krita](https://krita.org)（免费画图，可选）

### 第二步：找音效（30分钟）
1. 打开 https://kenney.nl/assets?q=audio
2. 下载 "Interface Sounds" 和 "Impact Sounds" 包
3. 解压，按 2.1 节重命名文件
4. 放到 `game-godot/assets/audio/sfx/` 目录

### 第三步：改代码（让 AI 帮你）
1. 复制本大纲到新对话
2. 说："请按大纲阶段1实施，先做 SFX 音效"
3. AI 会改 `sound_manager.gd` 和各调用点
4. 运行游戏测试

### 第四步：找 BGM（30分钟）
1. 打开 https://pixabay.com/music/
2. 搜索 "rpg battle" / "fantasy" / "calm"
3. 下载 5 首风格统一的曲子
4. 用 Audacity 转成 .ogg 格式
5. 放到 `game-godot/assets/audio/bgm/` 目录

### 第五步：继续阶段2-5
每完成一个阶段，开新对话粘贴大纲，说"请按阶段X实施"。

**核心原则**：每一步都先测，再做下一步。不要一次改太多。
